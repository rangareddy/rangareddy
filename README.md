<h2>Hi 👋, I'm Ranga Reddy</h2>

<p>
  <b>Data engineer working on open lakehouse systems</b> &nbsp;·&nbsp;
  <a href="https://github.com/apache/hudi">Apache Hudi</a> contributor &nbsp;·&nbsp;
  Bengaluru, India
</p>

I spend my time on the storage layer of the lakehouse: how a table applies a
stream of changes efficiently, what it costs to read afterwards, and which knob
is actually responsible when a job slows down. Most of that is Apache Hudi,
Apache Iceberg and Apache Spark, at @onehouse.

---

### 🧰 What I work on

| Area | What that means day to day |
|:--|:--|
| **Apache Hudi** | Indexes, the timeline, compaction and table services. Where most of my open-source time goes |
| **Apache Spark** | Tuning the write and read paths, memory and shuffle behaviour, and diagnosing jobs that got slower without changing |
| **Open table formats** | Hudi, Iceberg and Delta Lake, plus Apache XTable for reading one copy of the data as any of them |
| **Platform** | Kafka and Flink ingestion, catalogs, and the maintenance jobs a lakehouse quietly needs |

### ✍️ Writing

I write long-form guides and reference sheets at
**[rangareddy.github.io](https://rangareddy.github.io/)**. The ones people come
back to:

| | |
|:--|:--|
| [Apache Spark cheat sheet](https://rangareddy.github.io/ApacheSparkCheatSheet/) | Execution model, memory, joins, shuffle, AQE, Catalyst, streaming and tuning, with the default and version for every config |
| [Apache Hudi cheat sheet](https://rangareddy.github.io/ApacheHudiCheatSheet/) | Table types, timeline, indexes, the metadata table, concurrency, table services and migration |
| [Apache Iceberg cheat sheet](https://rangareddy.github.io/ApacheIcebergCheatSheet/) | Snapshot tree, hidden partitioning, row-level modes, procedures and maintenance |
| [Apache Hudi: a complete guide](https://rangareddy.github.io/ApacheHudiGuide/) | What Hudi is, how a write and a read actually work, and what is genuinely different about it |
| [Open table formats in practice](https://rangareddy.github.io/OpenTableFormats/) | What actually differs between Iceberg, Hudi and Delta Lake, past the feature checklist |

Everything in those is read from the release tag rather than recalled, which is
the whole point of them.
